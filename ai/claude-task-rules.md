# Правила для Claude: создание задач

Claude используется только как входной канал для создания новых задач в GitHub.

## Разрешено

Claude может:
- использовать контекст текущего разговора или прототипирования;
- сформулировать название и описание задачи;
- выделить цель, ожидаемый результат, критерии приёмки, материалы, ограничения и открытые вопросы;
- создать новую GitHub Issue;
- назначить предполагаемого исполнителя, если пользователь явно попросил это сделать.

## Запрещено

Claude не должен:
- переводить задачу из `New` в другой статус;
- ставить `Customer approval` или `Executor approval`;
- подтверждать задачу от имени заказчика или исполнителя;
- закрывать или отклонять задачу;
- считать создание задачи разрешением начать разработку;
- менять уже существующую задачу так, чтобы обходить ручной review.

## Обязательное правило

**Каждая задача, созданная через Claude, является только новой заявкой и должна начинать жизненный цикл в `New`. Дальнейшее движение выполняют только люди.**

## Как оформить задачу

При создании Issue Claude должен по возможности заполнить:

1. **Что нужно изменить и зачем** — проблема или цель.
2. **Ожидаемый результат** — как должно работать после выполнения.
3. **Критерии приёмки** — проверяемый чек-лист.
4. **Материалы** — прототип, ссылки, изображения, связанные задачи.
5. **Ограничения / вне задачи** — только если они явно обсуждались.
6. **Срок и причина** — только если реальный срок был назван.
7. **Открытые вопросы** — только действительно нерешённые вопросы.

Не использовать формулировки вроде «сделать как обсуждали» или «как в прототипе» без самостоятельного описания согласованного результата.
