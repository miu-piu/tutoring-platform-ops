# Tutoring Platform Ops

Операционный репозиторий проекта.

Здесь живут:

- постановка и согласование задач через GitHub Issues;
- правила рабочего процесса;
- инструкции для AI-инструментов;
- HTML-прототип базы знаний, который позже будет интегрирован в платформу.

## Главное правило

**Telegram — обсуждение. GitHub — задачи, договорённости и статус выполнения.**

Любая новая задача независимо от источника сначала создаётся как **New**. Начало разработки возможно только после ручного просмотра и подтверждения постановки заказчиком и исполнителем.

## Структура

- `.github/ISSUE_TEMPLATE/` — форма постановки новой задачи;
- `process/` — правила движения задач;
- `ai/` — правила постановки задач через Claude и другие AI-инструменты;
- `prototype/` — HTML-прототип базы знаний.
