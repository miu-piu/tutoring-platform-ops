# Tutoring Platform Ops

Репозиторий используется только как трекер задач проекта.

## Главное правило

**Telegram — обсуждение. GitHub — задачи, договорённости и статус выполнения.**

Любая новая задача независимо от источника сначала создаётся как **New**. Создание задачи не означает, что она принята в работу.

До начала разработки задача проходит ручной просмотр и согласование. Для перехода в работу нужны два отдельных подтверждения:

- заказчика — постановка отражает нужный результат;
- исполнителя — постановка понятна и может быть взята в работу.

## Что находится в репозитории

- `.github/ISSUE_TEMPLATE/` — обязательная форма постановки новой задачи;
- `process/` — правила движения задач по статусам;
- `ai/` — правила создания задач через Claude и другие AI-инструменты.
